# HOW TO USE (UR3 MuJoCo Data Pipeline)

This guide shows the exact commands to:

1. Create data
2. Visualize data
3. Verify data/simulation quality
4. Play MuJoCo simulations

Run all commands from:

```powershell
cd d:\Project\mujoco\ur3_mujoco_data
```

---

## 1) Install dependencies

```powershell
pip install mujoco numpy scipy h5py matplotlib pyyaml
```

Optional (only for JAX training prep):

```powershell
pip install jax jaxlib
```

---

## 2) Quick MuJoCo model checks and viewer

Inspect model/joints/site mapping:

```powershell
python scripts\inspect_model.py
```

Open MuJoCo viewer (robot idling in scene):

```powershell
python scripts\view_model.py
```

---

## 3) Create data

### A. Create one trajectory (quick sanity run)

```powershell
python scripts\run_single_trajectory.py
```

Output:
- `data\single_trajectory.h5`

### B. Create split-based kinematics dataset (recommended)

Debug-sized dataset:

```powershell
python scripts\generate_kinematics_dataset.py --config configs\kinematics_debug.yaml --output data\debug\ur3_kinematics_debug.h5
```

Small dataset:

```powershell
python scripts\generate_kinematics_dataset.py --config configs\kinematics_small.yaml --output data\small\ur3_kinematics_small.h5
```

Main dataset:

```powershell
python scripts\generate_kinematics_dataset.py --config configs\kinematics_main.yaml --output data\main\ur3_kinematics_main.h5
```

---

## 4) Visualize data

Generate trajectory/debug plots from a dataset:

```powershell
python scripts\plot_kinematics_dataset.py --dataset data\small\ur3_kinematics_small.h5 --output-dir data\small\plots
```

Inspect dataset structure and tensor shapes:

```powershell
python scripts\inspect_kinematics_dataset.py --dataset data\small\ur3_kinematics_small.h5
```

Optional notebook exploration:

```powershell
jupyter notebook notebooks\inspect_dataset.ipynb
```

---

## 5) Verify data and simulation

Validate joint mapping + kinematics consistency:

```powershell
python scripts\validate_kinematics.py
```

Validate end-effector velocity logging against finite difference:

```powershell
python scripts\validate_velocity.py
```

Validate generated kinematics dataset and write report:

```powershell
python scripts\validate_kinematics_dataset.py --dataset data\small\ur3_kinematics_small.h5 --config configs\kinematics_small.yaml
```

Outputs include:
- `data\validate_joint_order.png`
- `data\validate_velocity.png`
- `docs\VALIDATION_REPORT.md`

---

## 6) Play / replay simulation from saved data

Replay a trajectory from the legacy single-trajectory file:

```powershell
python scripts\replay_dataset.py --file data\single_trajectory.h5 --trajectory trajectory_000
```

Replay a trajectory stored inside the kinematics dataset:

```powershell
python scripts\replay_kinematics.py --dataset data\debug\ur3_kinematics_debug.h5 --group debug_trajectories/single_joint_sine/traj_000 --speed 1.0 --loop
```

Close the MuJoCo viewer window to stop playback.

---

## 7) Typical end-to-end workflow

```powershell
python scripts\inspect_model.py
python scripts\generate_kinematics_dataset.py --config configs\kinematics_small.yaml --output data\small\ur3_kinematics_small.h5
python scripts\plot_kinematics_dataset.py --dataset data\small\ur3_kinematics_small.h5 --output-dir data\small\plots
python scripts\validate_kinematics_dataset.py --dataset data\small\ur3_kinematics_small.h5 --config configs\kinematics_small.yaml
python scripts\replay_kinematics.py --dataset data\small\ur3_kinematics_small.h5 --group debug_trajectories/multi_joint_sine/traj_000
```
